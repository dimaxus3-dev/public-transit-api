# Contributing

Thanks for your interest! This project favors **small, dependency-free,
well-tested changes**.

## Ground rules

- **Runtime dependencies stay minimal**: FastAPI + Uvicorn only. Ingest,
  routing and GTFS-RT parsing are stdlib by design — a PR that adds a runtime
  dependency needs a very good reason.
- **Never invent feed URLs.** Only add feeds whose `gtfs_static_url` you have
  actually verified. New curated feeds go to `feeds.json`; the world registry
  (`feeds_world.json`) is generated by `scripts/import_catalog.py` — don't
  edit it by hand.
- Python 3.9 compatibility is required (CI tests 3.9 and 3.12).

## Workflow

```bash
pip install -r requirements.txt
pip install pytest pytest-cov httpx ruff bandit

ruff check app/ scripts/ tests/ clients/python/   # must be clean
ruff format app/ scripts/ tests/ clients/python/  # auto-format
pytest tests/ -q --cov=app --cov-fail-under=75    # must pass
```

Tests build synthetic GTFS feeds and run them through the real ingest
pipeline — no network needed. If you touch routing/schedule/ingest logic,
add a regression fixture that exercises the edge case (see
`tests/test_api.py` for patterns: after-midnight times, delayed transfers,
hostile zips).

Open the PR against `main`; CI (lint, security scan, audit, tests, Docker
build) must be green.

## Reporting bugs

Include the feed id, the exact request, and the response body — every error
is RFC 7807, so the `detail` field usually pinpoints the problem.
