# Code of Conduct

This project follows the [Contributor Covenant v2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

**TL;DR:** be respectful, assume good intent, keep discussions technical.
Harassment, personal attacks and spam are not tolerated.

Report unacceptable behavior via a GitHub issue marked confidential or by
contacting [@dimaxus3-dev](https://github.com/dimaxus3-dev). Maintainers may
remove, edit, or reject contributions and interactions that violate this code.
